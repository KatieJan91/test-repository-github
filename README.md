# test-repository-github
testovaci repositar

git clone + odkaz z githubu- naklonuje remote repositar na lokalni pocitac
git status - ukaze nam v jakem stavu jsou soubory
git diff - ukaze nam presne zmeny v souboru
git add. - zastaguje vsechny zmenene (modified) soubory - vsechny zmenene soubory mi dej do stavu staged (pote dam git status, abych si overila, ze se stav zmenil)
git commit -m "" - ulozeni zmeny
git push - odeslat commit na remote repositar
git pull - stahneme si nove zmeny z remote repositare
